## 1. 方針
- **適合テスト**: `Repo` の契約(03 §2)を、`FakeRepo` と `repo_git`(実 git の一時リポジトリ)の両方に同じ入力で実行し、結果が一致することを確かめる。`derive` と `checks` の単体テストは `FakeRepo` を使う(L3 の単体テスト仕様が正本)。
- **結合テスト**は、実 git の一時リポジトリを入力に、`adapters`(`repo_git`、`cli`、`claude_hook`)と `scripts/gate.sh` を、モジュールの境界で確かめる。LLM に依存するものは含めない(手動確認は 02_system_tests.md の M01)。
- ID は `L2-Ixx`。各テストは `requirement` marker(`REQ-2026-010-Fnn`)を持つ。表の「要件」の列がそのタグ。
- 「現行」の列は、現行コードで実現できるか [データ: 2026-10-27]。現行のコードは `domain` / `services` / `integrations` の構成で、03 の構成とは別物のため、ほぼ「できない」。
